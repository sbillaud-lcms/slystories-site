SLY STORIES

Privacy Policy

Last updated: October 15, 2026

This policy describes how "Sly Stories uploader" (the "Application"), a private tool operated by the owner of the Sly Stories YouTube channel, handles data.

Use of YouTube API Services

The Application uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and data accessed through YouTube API Services is subject to the Google Privacy Policy.

Data the Application accesses

  • Permission to upload videos and set their metadata (title, description, tags, privacy status, scheduled publication time) on the authorized channel, to add a caption track to them and to add them to the channel's own playlist.
  • Read-only access to the authorized channel's own videos and their public statistics (views, likes, comments counts).
  • Read-only access to the channel's own YouTube Analytics reports (for example audience retention), used to improve future episodes.

The Application does not access any data about viewers as individuals, does not read comments' authors, and does not access any other channel.

How data is used and stored

  • Data is used only to publish the channel's own videos and to produce aggregate statistics for the channel owner.
  • The Application runs as a scheduled job in the channel owner's private GitHub repository. The OAuth token is kept there as an encrypted secret and is written to disk only for the duration of each run, then deleted.
  • Statistics are stored in a database kept in that private repository, accessible only to the channel owner.
  • No data is sold, shared with third parties, or used for advertising.
  • Statistics are refreshed daily; any statistic not refreshed for 30 days is deleted automatically.

Revoking access

Access can be revoked at any time from the Google account security settings: https://security.google.com/settings/security/permissions. Revoking access stops the Application immediately; the stored token then becomes unusable.

Cookies

This website and the Application do not use cookies or tracking technologies.

Contact

For any question about this policy, contact the channel owner through the contact details listed on the Sly Stories YouTube channel.
